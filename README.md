# engineering-control-plane

Architecture for an autonomous engineering control plane: a frozen specification in, a verified implementation candidate or a genuine escalation out, with no human relaying output between agents.

Agentic judgment for planning and review, deterministic code for state, gates and evidence, heterogeneous worker and reviewer models underneath, and disagreement between code and agents handled as a first-class state.

**Status:** core architecture defined; v0.1 in development. See [ARCHITECTURE.md](ARCHITECTURE.md).
